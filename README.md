# 🕌 Umra Flutter

> ⚠️ **Проект в разработке** - приложение находится в активной разработке

Flutter версия приложения Umra Guide для помощи мусульманам в совершении Умры.

## 📱 О проекте

Мобильное приложение-гид для совершения Умры с поддержкой нескольких языков (русский, английский, немецкий, французский, турецкий, индонезийский), аудио-гидом, временем намаза и пошаговыми инструкциями.

## ✨ Основные возможности

- 📖 Пошаговые инструкции для совершения Умры
- 🔊 Аудио-гид с произношением дуа
- 🕌 Время намаза и расчет времени молитв
- 🌍 Многоязычная поддержка (6 языков)
- 🎨 Несколько тем оформления
- 📱 Поддержка iOS и Android

## 🚀 Запуск проекта

```bash
flutter pub get
flutter run
```

## 📦 Основные зависимости

- `provider` - управление состоянием
- `just_audio` - проигрывание аудио
- `flutter_localizations` - локализация
- `adhan_dart` - расчет времени намаза
- `flutter_local_notifications` - уведомления

## 📁 Структура проекта

```
lib/
├── main.dart
├── models/          # Модели данных
├── providers/       # Провайдеры состояния
```
