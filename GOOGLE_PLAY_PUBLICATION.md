## Подготовка к публикации

### 1. Сборка релизного AAB файла

Выполните следующую команду в корне проекта:

```bash
flutter build appbundle --release
```

Результат будет находиться в:
```
build/app/outputs/bundle/release/app-release.aab
```

### 2. Тестирование релизной сборки

Перед загрузкой в Google Play рекомендуется протестировать релизную сборку:

```bash
# Установка на подключенное устройство
flutter install --release

# Или создание APK для тестирования
flutter build apk --release
```

**Что нужно проверить:**
- ✅ Все функции работают корректно
- ✅ Аудио воспроизводится
- ✅ Уведомления работают
- ✅ Privacy Policy доступна в настройках
- ✅ Производительность приложения
- ✅ Нет критических ошибок

## Процесс загрузки

### Шаг 1: Создание релиза

1. В Google Play Console перейдите в раздел "Производство" (Production)
2. Нажмите "Создать релиз"
3. Загрузите AAB файл: `build/app/outputs/bundle/release/app-release.aab`
4. Заполните примечания к релизу (Release notes):
   - Краткое описание изменений
   - Новые функции
   - Исправления ошибок

### Шаг 2: Тестирование перед публикацией

**Рекомендуется создать закрытую тестовую группу:**

1. Перейдите в раздел "Тестирование" → "Закрытое тестирование"
2. Создайте тестовую группу
3. Добавьте тестировщиков по email
4. Загрузите туда же AAB файл
5. Протестируйте приложение перед публичным релизом

### Шаг 3: Заполнение информации о контенте

1. **Контентный рейтинг**: Заполните анкету (категория: Религия, рейтинг: 4+)
2. **Целевая аудитория**: Укажите возрастную категорию (4+)
3. **Политика конфиденциальности**: Укажите URL (после размещения HTML файла)
4. **Данные о безопасности**: 
   - Приложение НЕ собирает данные
   - Все данные хранятся только локально
   - Нет передачи данных третьим лицам

### Шаг 4: Цены и распространение

1. Выберите страны распространения (или все страны)
2. Укажите цену (если приложение платное)
3. Настройте доступность

### Шаг 5: Публикация

1. Проверьте все разделы на наличие предупреждений
2. Убедитесь, что все обязательные поля заполнены
3. Нажмите "Отправить на проверку"
4. Ожидайте проверки (обычно 1-3 дня)
