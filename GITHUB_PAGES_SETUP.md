# Инструкция по размещению Privacy Policy на GitHub Pages

## Простая настройка (без создания отдельной ветки)

Файл `privacy-policy.html` уже находится в корне вашего проекта. Просто запушьте его в ваш текущий репозиторий и включите GitHub Pages.

### Шаг 1: Загрузить файл в репозиторий

Файл `privacy-policy.html` уже есть в проекте. Просто закоммитьте и запушьте его:

```bash
git add privacy-policy.html
git commit -m "Add privacy policy for Google Play"
git push origin main
```

(или `git push origin master`, если у вас ветка `master`)

### Шаг 2: Включить GitHub Pages

1. Откройте ваш репозиторий на GitHub (например: `https://github.com/yourusername/umra_flutter`)
2. Перейдите в **Settings** → **Pages** (в меню слева)
3. В разделе **Source**:
   - Выберите **"Deploy from a branch"**
   - Branch: выберите **`main`** (или `master` - вашу текущую ветку)
   - Folder: выберите **`/ (root)`**
4. Нажмите **Save**

**Важно:** Не нужно создавать отдельную ветку `gh-pages`! Используйте вашу текущую рабочую ветку.

### Шаг 3: Получить URL

После загрузки файла (обычно через 1-2 минуты) ваш Privacy Policy будет доступен по адресу:

```
https://yourusername.github.io/umra_flutter/privacy-policy.html
```

Замените `yourusername` на ваш GitHub username и `umra_flutter` на название вашего репозитория.

### Шаг 4: Использовать в Google Play Console

1. Войдите в [Google Play Console](https://play.google.com/console)
2. Перейдите в раздел **Политика конфиденциальности**
3. Вставьте URL: `https://yourusername.github.io/umra_flutter/privacy-policy.html`
4. Сохраните изменения

## Особенности файла

✅ **Поддержка двух языков:**
- Русский
- English

✅ **Автоматическое определение языка:**
- Файл автоматически определяет язык браузера пользователя
- Пользователь может переключить язык вручную с помощью кнопок вверху страницы

✅ **Адаптивный дизайн:**
- Корректно отображается на мобильных устройствах
- Красивый и современный интерфейс

## Альтернативный вариант (папка docs/)

Если вы хотите использовать более короткий URL, можно:

1. Создать папку `docs/` в корне репозитория
2. Переименовать `privacy-policy.html` в `index.html`
3. Переместить `index.html` в папку `docs/`
4. В настройках GitHub Pages выбрать папку `docs/`

Тогда URL будет: `https://yourusername.github.io/umra_flutter/`

## Проверка

После настройки GitHub Pages проверьте:
- ✅ Страница открывается по указанному URL
- ✅ Переключение языков работает
- ✅ Страница корректно отображается на мобильных устройствах
- ✅ Все ссылки работают

## Важно

⚠️ **URL нельзя изменить после публикации в Google Play!**
- Убедитесь, что URL правильный и стабильный
- Рекомендуется использовать GitHub Pages, так как это бесплатный и надежный хостинг
